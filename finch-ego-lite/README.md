# Ego Browser for Finch

Let Finch work directly on the web while you stay aware of every page the Agent opens and every task space it uses.

## What you can do

After enabling this mini tool, simply ask Finch to:

- “Open Taobao and check the current price of a Switch game.”
- “Research this product on Google and summarize the key findings.”
- “Check my store orders and pause when you need my confirmation.”
- “Fill in this web form, but let me review it before submitting.”

Finch opens websites in isolated Ego Lite task spaces. You do not need to learn browser automation or copy page content into the conversation manually.

## Follow the Agent’s work

The Ego button beside the Composer shows the current connection status. Open its menu to:

- see active task spaces and page counts;
- view each page title and website;
- jump directly to any page in Ego Lite;
- tell whether the Agent is working, waiting for you, or under user control;
- close a completed task space and all pages inside it.

When a task space contains many pages, the menu shows up to six at a time and lets you scroll through the rest.

## Take control when needed

For sign-in, CAPTCHA, payment confirmation, or other sensitive steps, the Agent can pause and hand the task space to you. When finished, choose “Let Agent continue” and Finch will resume from the same page.

Task spaces are isolated from your everyday browser windows while still being able to reuse your existing login state. The Agent does not compete with the pages you are currently using, and you can inspect or take over its workspace at any time.

## Get started

1. Install and launch [Ego Lite](https://lite.ego.app/) on macOS. Ego Lite is a browser designed for collaboration between people and AI Agents, and provides the web environment used by this mini tool.
2. Enable this mini tool in Finch.
3. Tell Finch which website to visit and what you want done.
4. Use the Ego button beside the Composer to follow progress, open pages, or take control.

> Ego Lite currently supports macOS only. On Windows or Linux, this mini tool explains that the platform is not supported and provides a link to the Ego Lite website for future updates.

## About Finch

[Finch](https://finchwork.app/) is a lightweight, easy-to-use desktop AI Agent. It combines conversation, memory, local files, Skills, and mini tools to turn natural-language ideas into real results.

Ego Browser for Finch gives Finch observable, interruptible web access: the Agent explores and acts, while you retain the ability to inspect and confirm its work.

# Ego Browser for Finch 中文说明

让 Finch 真正走进网页完成任务，同时让你随时知道 Agent 正在看什么、做什么。

## 它能帮你做什么

启用后，你可以直接对 Finch 说：

- “打开淘宝，帮我看看 Switch 游戏现在多少钱。”
- “去 Google 调研这个产品，把重要结论整理出来。”
- “登录后台检查订单，有需要我确认的步骤就停下来。”
- “打开这个网页，填写表单并在提交前让我检查。”

Finch 会在 Ego Lite 的独立任务空间中打开网页。你不需要学习浏览器自动化，也不用手动复制网页内容给 Agent。

## 随时看见 Agent 的工作现场

输入框旁的 Ego 按钮会显示当前连接状态。展开菜单后，你可以：

- 查看 Agent 正在使用的任务空间和页面数量；
- 看到每个页面的标题与所属站点；
- 点击任意页面，直接跳转到 Ego Lite 中查看；
- 分辨当前由 Agent 操作、等待你操作，还是由你控制；
- 在任务结束后关闭整个任务空间及其中的页面。

页面较多时，菜单最多展示六项并支持滚动，不会占满屏幕。

## 需要你操作时，控制权会交给你

登录、验证码、支付确认或其他敏感步骤需要你亲自处理时，Agent 可以暂停并把任务空间交给你。完成后点击“让 Agent 继续”，Finch 会从同一个页面接着工作。

任务空间与日常浏览窗口彼此独立，但可以沿用你已有的登录状态。这样 Agent 不会抢占你正在使用的浏览器页面，你也可以随时进入现场检查。

## 开始使用

1. 在 macOS 上安装并启动 [Ego Lite](https://lite.ego.app/)。Ego Lite 是专为人与 AI Agent 协作设计的浏览器，也是本小工具连接网页的运行环境。
2. 在 Finch 中启用本小工具。
3. 直接告诉 Finch 想访问的网站和要完成的事情。
4. 通过输入框旁的 Ego 按钮查看进度、打开页面或接管操作。

> Ego Lite 目前仅支持 macOS。在 Windows 或 Linux 上，本小工具会显示平台暂不支持，并提供 Ego Lite 官网入口了解后续进展。

## 关于 Finch

[Finch](https://finchwork.app/) 是一款轻量、易用的桌面 AI Agent。它能结合对话、记忆、本地文件、Skills 与小工具，把自然语言中的想法逐步变成真实结果。

Ego Browser for Finch 为 Finch 增加了可观察、可接管的网页操作能力：Agent 负责探索和执行，你始终保留查看与确认的权利。
