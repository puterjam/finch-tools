## 本次结果

- 改名直接将知识库原行切换为输入框，不调用宿主改名弹窗。Enter 保存、Esc 取消；提供保存与取消图标，支持中文输入法组合输入，保存失败保留草稿并恢复输入焦点。
- 编辑前后行高、菜单位置和邻行位置保持一致；取消和保存后焦点回到该行的改名按钮。改名不切库，不改源文件夹或其内容。
