# 知识库 0.25.3 整理说明

## 版本基线

2026-11-05 查询 npm：`finch-knowledge` 的 `latest` 为 **0.25.2**。按用户要求仅递增一个补丁版本，本次源码统一为 **0.25.3**，不采用此前本地测试包的 0.26.x 编号，也不升级到 0.27.0。已有测试安装包保留，不覆盖，不纳入 Git。

## 新增与完善

- Excel（XLS/XLSX）、PowerPoint（PPT/PPTX）沿用 AnyDoc 引擎索引；PDF 与 Office 交给宿主文档预览，旧宿主拒绝时回落文件管理器。随包保留 Office 图标许可，合成测试样本可由脚本复现。
- 建立独立版本化 SQL 文件清单，分批发现资料，支持六种排序、游标前后分页与阅读锚点恢复；列表不等待向量引擎或全目录文件属性读取。
- 知识库支持原行改名、确认移除和只读后台可用性检查；移除默认保留索引，明确勾选才将安全确认属于该库的索引移入系统回收站。源资料和共享引擎缓存不动。
- 设置与搜索入口整理，菜单各项使用明确的独立图标；支持隐藏不支持格式的显示偏好。目录打开图标与计数共用中心位置。

## 修复与优化

- 切库、中断、断盘、权限异常、共享身份变化及迟到结果均有边界保护；无法确认完整扫描的子树保留旧清单，不将暂不可访问误当文件删除。
- 原生 I/O 取消后保留安全退出屏障，重建旧索引先保留备份，清理索引先等待所有句柄关闭。
- 知识库菜单采用主题选中色，移除前置勾及空位，统一整行 hover，改名失败保留草稿；后台状态更新不重建输入节点。
- 文件列表最终交互：**不显示索引状态表头文字；平时显示状态，悬停/聚焦时在同一尾槽显示操作；不保留独立操作列**。正常、不支持、失败和待索引行使用相同规则，切换不引起布局位移。

## 提交范围与限制

按 Office、数据层、宿主管理桥接、界面及发布文档拆分提交。运行期缓存、临时截图、隔离验收目录、旧安装包与 `stash@{0}` 保留在本地，不进入提交。现有历史提交不 amend，不 force push。

此前各验证文档中的 0.26.x 表示本地迭代历史，最终版本以本说明及 `package.json` 为准。实际 Windows 回收站、Linux `gio trash`、SMB 断连/重映射、Finch 宿主 Office 预览仍有未实机验证范围；持久内容任务队列尚未实现。此次 Git 推送不等于 npm 发布，也不会安装或覆盖用户现有小程序。
